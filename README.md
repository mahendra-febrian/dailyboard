# Dailyboard

*Dailyboard* — dashboard produktivitas harian berisi daftar tugas (to-do list), catatan cepat (notes), hingga widget cuaca, seluruhnya dibangun dengan HTML, CSS, dan Javascript murni.

## Fitur

- Daftar Tugas
- Catatan Cepat
- Widget Cuaca
- Widget Kutipan

## Cara Pakai

- Ketuk setiap fitur yang relevan.
- Ketuk dua kali tugas atau catatan cepat untuk mengubahnya.

## Struktur

```
dailyboard\
    index.html
    style.css
    script.js
    tugas.js
    catatan.js
    storage.js
    api.js
```
